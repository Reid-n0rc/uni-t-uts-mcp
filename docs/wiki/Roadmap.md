# Roadmap

The live plan is the [roadmap issue #1](https://github.com/Reid-n0rc/uni-t-uts-mcp/issues/1), a checklist of the work that is left. The lists below are generated from the issue tracker whenever the wiki is rebuilt, so they track the project without anyone editing this page.

What is already in place: connection, raw SCPI, frequency, amplitude, bandwidth, sweep, detector, acquisition and trace configuration tools, tool calls that are safe to run in parallel, a VXI-11 transport next to raw TCP, install from npm, the release tarball, git tag or Docker image, and tests plus continuous integration on Linux, macOS and Windows. The screenshot tool works over VXI-11. What is still to come is mostly trace data fetch, markers and measurements.
